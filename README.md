## Featured Projects

### OpenCircle

A production social platform that helps people share plans, discover nearby activities, and connect without first building a follower network.

[Repository](https://github.com/abdulkhadir07/open-circle) · [Live application](https://open-circle-puce.vercel.app) · [API health](https://backend-production-1f35.up.railway.app/actuator/health)

- Location based city, region, country, and global invite feeds
- Temporary single and group invites with tags, editing, image uploads, engagement requests, and automatic expiration
- Real time chat, attachments, notifications, profiles, ratings, reputation, annual scoring, and account management
- Secure email verification, password recovery, revocable sessions, private S3 storage, and immediate account deletion
- Optional Gemini powered invite drafting and feed insights with built in fallback behavior

**Stack:** Java 21 · Spring Boot 4 · React 19 · TypeScript · PostgreSQL · WebSocket/STOMP · AWS S3 · Brevo · Gemini · Railway · Vercel

### OpenSFSU

An AI assisted campus community for SFSU students to find people to study, eat, and spend time with on campus.

[Repository](https://github.com/abdulkhadir07/opensfsu) · [Live application](https://opensfsu.vercel.app)

- 24 hour campus invites with join requests, host approval, group chat, ratings, points, and a community Banter board
- Gemini assisted invite drafting, campus digests, personalized matching explanations, icebreakers, and smart replies
- AI safety checks for contact details, harassment, scams, private residences, and risky meetup times
- Human review for AI suggestions and rule based fallbacks when model services are unavailable

**Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS · Prisma · PostgreSQL · Neon · Google Gemini · Vercel

### Linkcore

A digital wallet and remittance platform with a Spring Boot API and customer facing web application.

[Backend repository](https://github.com/abdulkhadir07/digital-wallet-api) · [Frontend repository](https://github.com/abdulkhadir07/wallet-frontend) · [Live application](https://linkcoreweb.netlify.app) · [API documentation](https://digital-wallet-api-551y.onrender.com/swagger-ui/index.html)

- JWT authentication, protected endpoints, and an append only wallet transaction ledger
- Multi currency conversion with domestic, international, and foreign exchange transfer pricing
- KYC aware transfer validation, deposits, withdrawals, recipient search, transaction history, and printable receipts
- Multi step registration, OTP verification, transfer quote previews, dashboard reporting, and profile management

**Stack:** Java 17 · Spring Boot 4 · PostgreSQL · Spring Security · JavaScript · Tailwind CSS · Docker · Render · Netlify
